# Vaλisp
A lisp written (almost) from scratch. The whole Vaλisp project, conducted as part of a C class of Olivier Baldelon.

## Features
Upon launching the REPL with `./valisp`, type `@aide` for additional commands.

### Load memory images
Memory images can be saved and loaded using `@save` and `@load` to test different features of Valisp's memory. Pre-saved memory images can be loaded from the `images_test` directory.

### Write Lisp code
> Note: All the next commands require using Emacs.

To write and execute lisp code, create a file with `.val` extension. Then, write all the code you want then press `F8` to launch Vaλisp. To evaluate a line of code, place your cursor next to the last character, then press `Ctrl + x` and `Ctrl + a`

Another option to evaluate several lines of code quickly would be to do `Ctrl + x` then press `a` as much as you want.
